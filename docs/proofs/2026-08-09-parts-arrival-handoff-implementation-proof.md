## What shipped in the candidate

- Parts, advisor, and owner roles can move each exact approved part through
  `Needs order → Ordered → Received` inside its existing approved job.
- The assigned technician receives the same arrival truth read-only.
- Every read and write binds the active persisted actor, tenant, open ticket,
  approved job, approved quote version, immutable quote snapshot, exact part-line
  commercial identity, and legal monotonic transition.
- Ordered and received receipts retain actor and server time. Exact replays settle
  idempotently; lock contention and stale truth fail closed.
- Receiving the final approved part reports `All parts here` without changing the
  ticket, job, quote, hold, assignment, work state, or price.
- Lost or malformed write responses reconcile once against fresh server truth;
  the browser never settles optimistically.
- The feature uses the existing `job_lines` fields. It adds no table, migration,
  page, provider connection, supplier request, order placement, hold release,
  permission expansion, or external dependency.
